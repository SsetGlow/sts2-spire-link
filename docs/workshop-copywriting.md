# Workshop 页面文案草稿

## 标题
Spire Link（尖塔共鸣）

## 简介短文
A co-op focused Slay the Spire 2 mod built around shared Resonance, Link-based teammate support, and team burst windows.

## 长描述
Spire Link turns teammate interaction into the core gameplay loop.

### Core mechanics
- Resonance: a shared team resource
- Link: queue support effects for the next teammate
- Resonate: spend or leverage Resonance for stronger payoffs

### First release content
- 8 cards
- 3 relics
- 1 team event

### Design goals
- Make every player feel like they are helping the team
- Encourage discussion around shared resource timing
- Create a loop of setup -> charge -> burst -> recovery
