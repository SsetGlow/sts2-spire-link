Spire Link 安装说明

1. 确保你已经安装 BaseLib mod。
2. 将当前文件夹“SpireLink”整体复制到 Slay the Spire 2 的 mods 目录下。
3. 启动游戏。

目标目录示例：
- Windows / Linux: <Slay the Spire 2>/mods/SpireLink/
- macOS: <Slay the Spire 2>/SlayTheSpire2.app/Contents/MacOS/mods/SpireLink/

当前目录应该至少包含：
- SpireLink.dll
- SpireLink.pck
- SpireLink.json

如果缺少 dll / pck，说明这是源码仓库里的发布模板，还不是最终玩家包。
